固件术语速查

这是首次介绍用的参考表，不是已掌握知识清单。

术语在本项目中的含义
源码人可以修改的 C 程序及配置，描述计时、界面和保存行为。
ESP-IDFEspressif 的开发框架和工具链，用来构建 ESP32-C3 应用。
编译 / Build把源码和依赖转换成芯片能执行的程序及相关产物；不会自行改变设备。
固件 / .bin供设备运行的二进制程序或安装镜像；app-only 与 merged image 用途不同。
烧录将程序写入设备 Flash 的操作，需要选对目标和地址。
RAM运行时临时内存，掉电后正在计时的状态与所有尚未保存的记录丢失。
Flash断电后仍能保留程序和数据的存储器，分区用于分开不同内容。
NVS / commitFlash 中的键值存储 / 提交改动。本应用只有提交成功才把结果作为已保存记录。
bootloader启动应用之前运行的引导程序；按分区信息选择要加载的应用。
Recovery旧布局里主应用之外的恢复程序。当前默认分区表不再包含它；设备上是否还在，取决于还没有按新布局整片烧录。
BSP仓库已有的板级驱动接口，包括显示、按键与音频；计时应用复用它们。
