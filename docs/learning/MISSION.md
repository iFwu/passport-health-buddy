# 学习目标：理解并使用离线平板支撑计时器

## 为什么学

用户希望把已连接的 AI Passport 用作专用平板支撑自由计时器，并理解更新固件到底改变了什么。能自主开始、结束和查看记录，也知道什么时候结果还没有保存。

## 达成时能做到

- 说清源码经 ESP-IDF 编译为 `.bin`，安装进 Flash 后由设备独立运行。
- 按三键完成一次自由计时，找到最近记录，分辨保存成功与待重试。
- 区分 RAM 中的临时状态和 Flash 中已提交的历史，说明掉电影响。
- 知道 Recovery 的用途，以及安装前需要保留设备身份和 Recovery。

## 约束

用户自称固件新手。课程用简体中文，术语保留 English，内容短小并提供即时反馈；目前只做自由计时，短时记录与长时记录同等处理。练习使用浏览器模拟，不操作真实设备。

## 不涉及

目标倒计时、排名、破纪录、姿势识别、医疗或训练指导；驱动开发和电路改造。学习课程不授权烧录、擦除或上传。
